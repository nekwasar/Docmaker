# Docmaker — Complete Product Documentation

## What Is Docmaker

Docmaker is an all-in-one document platform. You can generate, convert, translate, extract text, merge, split, compress, restyle, edit, and sign documents — all in one place, all for free.

No subscription required. No watermarks. No tab switching between five different websites. Just documents, done smoothly.

## Core Promise

**Free for basic. AI-powered for perfect. You choose.**

Every tool works immediately — no account, no credit card. If you want AI-enhanced quality, you pay with credits. If not, the basic version is always free.

## Target Users

### 1. Daily Internet Users (Power Users)

**Who:** Freelancers, students, content creators, remote workers, solopreneurs, researchers

**What they do EVERY DAY:**

| Task | Frequency | Current Pain |
|------|-----------|--------------|
| Convert files (PDF↔Word, JPG→PDF) | 5-20x/day | Smallpdf limits to 2/day, uploads files |
| Merge/split PDFs | 3-10x/day | Need multiple tools, watermarks |
| Generate documents from text | 2-5x/day | Copy-paste between ChatGPT and Word |
| Translate content | 1-3x/day | Google Translate = bad formatting |
| Extract text from images/PDFs | 2-5x/day | OCR tools charge per page |
| Compress PDFs for email | 3-5x/day | File too large, can't attach |
| Sign PDFs | 1-2x/day | DocuSign charges $10+/mo |
| Edit PDFs (add text, annotate) | 2-5x/day | Adobe charges $20+/mo |

**#1 frustration:** "I need to convert a PDF, then merge it, then add a signature. That's 3 different websites, 3 accounts, 3 limits."

### 2. Enterprise Users

**Who:** Companies, teams, HR departments, legal firms, agencies, startups

**What they do EVERY DAY:**

| Task | Frequency | Current Pain |

**#1 frustration:** "We spend $500+/month on DocuSign + Smallpdf + Adobe for our team. There's no single affordable solution."

| Tool | What It Does | Price | Weakness |
|------|--------------|-------|----------|
| **Smallpdf** | 30+ PDF tools | $9/mo | Only 2 free tasks/day, uploads files |

| **aidocmaker.com** | AI document generator | Free | AI only, no PDF tools, no editing |
| **Gamma.app** | AI presentations | $12/mo | Slides only, no PDF tools |
| **DocuSign** | E-signatures | $10+/mo | Expensive, single purpose |
| **Adobe** | PDF editing | $20+/mo | Very expensive |
| **PDFSnap** | Privacy-first PDF tools | Free | No AI, no document generation |
| **Google Drive** | Docs + limited PDF | Free | Basic PDF tools only |

### Our Competitive Moats

1. **"Everything Free"** — Undercut Smallpdf/iLovePDF (they charge $9/mo)
2. **"Privacy First"** — Process in browser like PDFSnap (unique with AI)
3. **"AI + Tools"** — Only platform with BOTH (aidocmaker = AI only, Smallpdf = tools only)
4. **"E-Signatures Included"** — Beat DocuSign ($10+/mo) by including free
5. **"Document Q&A"** — Upload doc, ask questions (nobody does this well)
6. **"File Transfer"** — Send files between devices (unique on mobile)
7. **"Multi-Platform"** — Same features, optimized experience per platform

## Technical Architecture

### Tech Stack

- **Frontend:** Next.js 14 (App Router), React, TypeScript
- **Mobile:** React Native (iOS/Android)
- **Backend:** Next.js API Routes
- **Database:** MongoDB (Mongoose), Redis (ioredis)
- **Auth:** JWT + OAuth (Google)
- **AI:** OpenAI/Anthropic API
- **Real-time:** Socket.io
- **Container:** Docker + Docker Compose

### Key Features

- Real-time AI streaming via WebSocket
- Browser-based file processing (privacy-first)
- Admin panel with full control
- SEO-optimized static pages
- Mobile-responsive design
- Cross-platform file transfer
- Universal file viewer

## Development

### Getting Started

```bash
# Clone the repository
git clone https://github.com/nekwasar/docmaker.git

# Install dependencies
npm install

# Start development server
npm run dev

# Or use Docker
npm run dev:docker
```

### Available Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Next.js dev server |
| `npm run build` | Production build |
| `npm run start` | Production server |
| `npm run lint` | ESLint (0 warnings) |
| `npm run type-check` | TypeScript check |
| `npm run dev:docker` | Docker dev mode |
| `npm run prod:docker` | Docker prod mode |
