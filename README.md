# Docmaker

All-in-one document platform. Generate, convert, edit, translate, and sign documents — all in one place.

## What It Does

| Tool | What It Does | Cost |
|------|--------------|------|
| **Generate** | Create documents from text prompts using AI | Free |
| **Convert** | Convert between 200+ file formats | Free |
| **Merge PDF** | Combine multiple PDFs into one | Free |
| **Split PDF** | Separate PDF into pages | Free |
| **Compress PDF** | Reduce PDF file size | Free |
| **OCR** | Extract text from images and PDFs | Free |
| **Translate** | Translate documents between languages | Free |
| **Voice to Doc** | Record voice and get formatted document | Free |
| **Change Style** | Restyle any document with AI | Free |
| **E-Sign** | Sign documents digitally | Free |
| **Edit PDF** | Add text, images, annotations to PDFs | Free |
| **AI Q&A** | Ask questions about your documents | Free |

## Target Users

- **Daily Internet Users** — Freelancers, students, remote workers
- **Enterprise** — Teams, companies, agencies
- **Mobile Users** — Phone-first users, field workers

## Key Differentiators

1. **Everything Free** — No limits, no watermarks, no paywalls
2. **Privacy First** — Process files in-browser when possible
3. **AI + Tools** — Only platform with both document generation and PDF utilities
4. **No Signup Required** — Use immediately, no account needed

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- MongoDB + Redis
- Docker
- Socket.io (real-time streaming)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or use Docker
npm run dev:docker
```
